Bibliotecas de terceiros usadas pelo FreeSCP (reescrita em Rust)
(Excluem-se frameworks do sistema operacional como Security e AppKit no macOS,
e o Secret Service do sistema no Linux.)

Interface gráfica
- Slint
  Descrição: toolkit declarativo de interface gráfica (janelas, widgets, suporte a gettext).
  Licença: GPL-3.0-only OR LicenseRef-Slint-Royalty-free-2.0 OR LicenseRef-Slint-Software-3.0
  Site: https://slint.dev/
  Copyright: SixtyFPS GmbH

  Licença: Apache-2.0
  Site: https://github.com/warp-tech/russh

- russh-sftp
  Descrição: implementação do protocolo SFTP sobre o russh.
  Licença: Apache-2.0
  Site: https://github.com/AspectUnk/russh-sftp
  Copyright: The russh-sftp developers
- suppaftp
  Descrição: biblioteca cliente FTP/FTPS.
  Licença: MIT OR Apache-2.0
  Site: https://github.com/veeso/suppaftp
  Copyright: Christian Visintin and contributors
- reqwest
  Descrição: cliente HTTP usado pelo backend WebDAV.
  Licença: MIT OR Apache-2.0
  Site: https://github.com/seanmonstar/reqwest
  Copyright: Sean McArthur and contributors
- quick-xml
  Descrição: parser XML usado nas respostas PROPFIND do WebDAV.

- tokio-socks
  Descrição: suporte a proxy SOCKS5 para os backends de protocolo.

  Copyright: The tokio-socks developers
